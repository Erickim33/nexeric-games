About

Built by one developer.
Growing one game at a time.

Nexeric Games is an independent game studio created by Eric Kimani, a self-taught developer from Kenya.

Nexeric Games started with a simple idea: make games, release them, learn from players, and keep building.

I'm interested in creating games that are easy to understand, fun to play, and different enough to make players want to come back.

The Creator

Eric Kimani

Founder · Game Developer · Programmer

I started learning software development independently and gradually turned that interest into game development.

I work across the different parts of a game — from programming and gameplay systems to interface design, testing, publishing, and improving the experience based on how people actually play.

Nexeric Games is currently being built as a small independent studio, with the goal of growing into something much bigger over time.

The Games

More games are already being explored and developed for the future.

Why Nexeric Games?

I don't want Nexeric Games to be a studio that makes only one type of game.

The goal is to experiment with different ideas, genres, mechanics, and ways of playing.

Some games may be simple.
Some may be ambitious.
Some may fail.

But every project is part of the process of becoming a better developer and building better games.

What's Next?

Nexeric Games is just getting started.

The long-term goal is to build a growing collection of original games that players can discover, play, and share — while continuing to learn and improve with every release.

Two games are the beginning. Not the limit.

Thanks for playing.
